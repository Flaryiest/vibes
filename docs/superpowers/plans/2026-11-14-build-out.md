## How it was checked

- Unit tests for every pure module (`pnpm test`), server tests (`node --test` in `server/`), and end-to-end tests in Chrome with a fake microphone (`pnpm e2e`).
- The end-to-end tests cover: the lab hearing a tone; key and tempo change staying in sync; the in-tune, one-octave-low and two-semitones-low verdicts; the range finder; opening a song and choosing a key; a scored phrase repetition with progress kept; saving a corrected note to disk; a recorded and scored run-through; a whole sped-up session ending in a backup on disk; the pitch check; the progress screen.
- Every screen was screenshotted and reviewed against the design rules.
- The import tool was run end to end on a freely licensed song, and that package was loaded in the app: key picker, audition, phrase practice and the note editor.

**Not checked by anyone yet:** a real voice, a real microphone, AirPods, and the owner's own songs. The by-hand checks in the audio-lab plan (Task 12) and the practice-loop plan (Task 11) still stand.

## Differences from the spec

| Spec | Built | Why |
|---|---|---|
| Song files served under `/songs/` | Served under `/song-files/` | `/songs` is one of the app's own screens |
| Scoring with SwiftF0 in the browser (check 8) | McLeod tracker with a 4096-sample window | The spec's stated fallback; SwiftF0 in the browser was not attempted |
| Editing a phrase's notes resets that phrase's progress | Saving notes resets the whole song's progress | Simpler, and phrase numbering can shift after an edit |
| The run-through covers "everything learned so far" | It covers the whole song, and the session offers it only once every phrase has reached full-speed words on headphones | A partial take reads as "too little heard" |
| Foundation levels F4 and F5 (patterns drawn from the current song) | Levels 1–4 are range-based only | Not built |
| Warm-up glides refine the stored range daily | The range changes only through the range finder | Not built |
| Audio is kept for starred takes, time capsules and each day's best take | The same, without starring: there is no way to star a take yet | Starring was not built |
| Own-voice guide bank; baked key variants used by the player; original-versus-learner overlay | Not built | Phase 5 items left for later |
| Phone support | Not built | Out of scope in the spec |
