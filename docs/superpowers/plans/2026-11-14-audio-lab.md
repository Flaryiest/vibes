# Audio Lab Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build the audio lab (pinned-microphone capture, a live pitch line, loopback calibration and measurement panels) and use it to verify checks 1–6 from the spec on this MacBook.

**Architecture:** A Vite + React + TypeScript single-page app under `app/`. All signal logic is pure TypeScript with unit tests. A thin audio engine (AudioWorklet → Web Worker) turns microphone audio into a stream of pitch frames that a canvas and the lab panels subscribe to. React holds only low-rate state.

**Tech Stack:** Vite, React, TypeScript, Tailwind, `pitchy` (its `Autocorrelator` only), Vitest, Playwright driving the installed Chrome with a fake microphone, and one `uv` script using `swift-f0`.

**Spec:** `docs/superpowers/specs/2026-11-13-singing-trainer-design.md`, build phase 0.

**Two deliberate differences from the spec:**

1. **Checks 7 and 8 are deferred to the songs plan.** Check 7 (the key and tempo stretcher) and check 8 (SwiftF0 running in the browser) are not needed until song playback exists. SwiftF0 is still compared against the live detector on the learner's own low notes here, offline in Python (Task 9).
2. **The live detector is a band-restricted McLeod implementation from the start.** The spec named this as the fallback. A prototype showed `pitchy`'s `PitchDetector.findPitch` reports clarity up to 0.996 on white noise, because it accepts peaks at very long lags where almost no samples overlap. The version in Task 3 searches only lags inside the allowed pitch band and was prototyped at 48 kHz and 44.1 kHz: 0 octave errors, worst error 6.7 cents, white-noise clarity at most 0.124.

**Status (2026-11-14):** Tasks 1-11 are built, tested and committed on `audio-lab`. Task 12 and the two by-hand checks (Task 7 step 10, the by-hand part of Task 8 step 6) need the learner at the machine.

**Screen styling differs from the code blocks below.** The screens were built to the design tokens in `app/src/index.css` (navy field, chalk text, brass reserved for the voice, Instrument Sans) rather than the class names shown in this plan's interface code. Behavior, component names and test ids are as planned, with one exception: the status badge shows friendly text and the end-to-end test reads its `data-state` attribute.

## Global Constraints

- Chrome only. Any other browser gets a blocking message.
- The app is always opened at `http://localhost:4747`. The dev and preview servers use that port with `strictPort`, so the microphone permission and stored data stay on one origin.
- One `AudioContext({ latencyHint: "interactive" })` for playback and capture.
- Microphone constraints, exactly: `{ deviceId: { exact: id }, echoCancellation: false, noiseSuppression: false, autoGainControl: false, channelCount: 1 }`.
- The microphone is the built-in one: an `audioinput` whose label matches `/MacBook.*Microphone/i`, ignoring entries whose id is `"default"` or whose label starts with "Default".
- Live detection: 2048-sample window, 512-sample hop, band never below 55 Hz or above 700 Hz, clarity at least 0.5, median of 5 frames, octave guard for jumps of 1100–1300 cents lasting under 60 ms, timestamp at the window center.
- Only the entry point `app/src/main.tsx` and files under `app/src/ui/` import React. The pitch stream never enters React state.
- No GPL or AGPL dependencies (`pitchfinder`, `aubio`, `essentia.js` are excluded).
- `songs/` and `data/` are git-ignored.
- The existing documents are committed to `main` first; all code is committed on the `audio-lab` branch, one commit per task.

```ts
export function isChromium(brands: readonly { brand: string }[] | undefined, userAgent: string): boolean {
  if (brands && brands.length > 0) {
    return brands.some((b) => b.brand === "Chromium" || b.brand === "Google Chrome");
  }
  return /Chrome\/\d+/.test(userAgent);
}
```

```ts
const NAMES = ["C", "C♯", "D", "D♯", "E", "F", "F♯", "G", "G♯", "A", "A♯", "B"];

export const hzToMidi = (hz: number): number => 69 + 12 * Math.log2(hz / 440);

export const midiToHz = (midi: number): number => 440 * 2 ** ((midi - 69) / 12);

export const centsBetween = (hz: number, refHz: number): number => 1200 * Math.log2(hz / refHz);

export function midiToName(midi: number): string {
  const m = Math.round(midi);
  return `${NAMES[((m % 12) + 12) % 12]}${Math.floor(m / 12) - 1}`;
}

export function describePitch(hz: number): { name: string; cents: number } {
  const midi = hzToMidi(hz);
  const nearest = Math.round(midi);
  // "+ 0" turns a negative zero into zero.
  return { name: midiToName(nearest), cents: Math.round((midi - nearest) * 100) + 0 };
}
```

`app/src/dsp/stats.ts`:

```ts
export function percentile(values: number[], p: number): number {
  if (values.length === 0) return NaN;
  const sorted = [...values].sort((a, b) => a - b);
  const position = p * (sorted.length - 1);
  const low = Math.floor(position);
  const high = Math.ceil(position);
  return sorted[low] + (sorted[high] - sorted[low]) * (position - low);
}

export const median = (values: number[]): number => percentile(values, 0.5);
```

```ts
/** Harmonic amplitudes of a full voice, strongest at the fundamental. */
export const FULL_VOICE = [1, 0.8, 0.6, 0.45, 0.3, 0.2];

/** The same voice through a microphone that barely picks up the fundamental. */
export const WEAK_FUNDAMENTAL = [0.05, 1, 0.8, 0.6, 0.4, 0.3];

export type ToneOptions = {
  hz: number;
  seconds: number;
  sampleRate: number;
  harmonics?: number[];
  level?: number;
  noise?: number;
  seed?: number;
};

/** Uniform values in [-0.5, 0.5), repeatable for a given seed. */
function random(seed: number): () => number {
  let s = seed >>> 0;
  return () => {
    s = (s * 1664525 + 1013904223) >>> 0;
    return s / 2 ** 32 - 0.5;
  };
}

export function harmonicTone(o: ToneOptions): Float32Array<ArrayBuffer> {
  const { hz, seconds, sampleRate, harmonics = FULL_VOICE, level = 0.5, noise = 0, seed = 1 } = o;
  const n = Math.round(seconds * sampleRate);
  const out = new Float32Array(n);
  const next = random(seed);
  let peak = 1e-9;
  for (let i = 0; i < n; i++) {
    let v = 0;
    for (let h = 0; h < harmonics.length; h++) {
      v += harmonics[h] * Math.sin((2 * Math.PI * hz * (h + 1) * i) / sampleRate + h * 0.7);
    }
    out[i] = v;
    peak = Math.max(peak, Math.abs(v));
  }
  for (let i = 0; i < n; i++) out[i] = (level * out[i]) / peak + noise * 2 * next();
  return out;
}

export function whiteNoise(samples: number, level: number, seed = 1): Float32Array<ArrayBuffer> {
  const out = new Float32Array(samples);
  const next = random(seed);
  for (let i = 0; i < samples; i++) out[i] = level * 2 * next();
  return out;
}
```

```ts
import { centsBetween } from "../dsp/music";
import { FULL_VOICE, WEAK_FUNDAMENTAL, harmonicTone, whiteNoise } from "../dsp/synth";
import { createBandMpm } from "./bandMpm";

const BAND = { minHz: 55, maxHz: 700 };
// C2, D2, E2, G2, A2, C3, G3, C4, E4, A4, E5
const NOTES = [65.41, 73.42, 82.41, 98, 110, 130.81, 196, 261.63, 329.63, 440, 659.25];

describe("createBandMpm", () => {
  for (const sampleRate of [48000, 44100]) {
    for (const windowSize of [2048, 4096]) {
      it(`tracks low and high notes within 10 cents at ${sampleRate} Hz, window ${windowSize}`, () => {
        const detect = createBandMpm(windowSize, sampleRate, BAND);
        for (const harmonics of [FULL_VOICE, WEAK_FUNDAMENTAL]) {
          for (const noise of [0, 0.02, 0.05]) {
            for (const hz of NOTES) {
              const x = harmonicTone({ hz, seconds: 0.6, sampleRate, harmonics, noise });
              for (let start = 0; start + windowSize <= x.length; start += 512) {
                const r = detect(x.subarray(start, start + windowSize));
                expect(r.hz, `${hz} Hz`).not.toBeNull();
                expect(Math.abs(centsBetween(r.hz!, hz)), `${hz} Hz`).toBeLessThan(10);
                expect(r.clarity, `${hz} Hz`).toBeGreaterThan(0.9);
              }
            }
          }
        }
      });
    }
  }

  it("gives white noise a low clarity", () => {
    const detect = createBandMpm(2048, 48000, BAND);
    const x = whiteNoise(2048 * 200, 0.05, 99);

    for (let i = 0; i < 200; i++) highest = Math.max(highest, detect(x.subarray(i * 2048, (i + 1) * 2048)).clarity);

    expect(detect(x.subarray(0, 2048)).hz).toBeNull();
```

```ts
import { Autocorrelator } from "pitchy";

export type Band = { minHz: number; maxHz: number };
export type Estimate = { hz: number | null; clarity: number };

/**
 * McLeod pitch method, searching only the lags that correspond to `band`.
 *
 * Limiting the lag range matters: at lags near the window length almost no
 * samples overlap, so the normalized difference function can hit 1.0 by chance
 * and noise gets reported as a confident very low pitch.
 *
 * A tone above `band.maxHz` can be reported one octave down. Keep the band wide
 * enough to cover the singer.
 */
export function createBandMpm(
  windowSize: number,
  sampleRate: number,
  band: Band,
  k = 0.9,
): (input: Float32Array) => Estimate {
  const autocorrelator = Autocorrelator.forFloat32Array(windowSize);
  const nsdf = new Float32Array(windowSize);
  const minLag = Math.max(2, Math.floor(sampleRate / band.maxHz));
  const maxLag = Math.min(Math.ceil(sampleRate / band.minHz), Math.floor(windowSize / 2) - 1);

  return (input) => {
    autocorrelator.autocorrelate(input, nsdf);
    let m = 2 * nsdf[0];
    if (!(m > 0)) return { hz: null, clarity: 0 };

    // Normalized square difference function, for the lags that are needed.
    for (let i = 0; i <= maxLag + 1; i++) {
      const r = nsdf[i];
      nsdf[i] = m > 0 ? (2 * r) / m : 0;
      m -= input[i] ** 2 + input[windowSize - 1 - i] ** 2;
    }

    // Key maxima: the highest point between each upward and downward zero crossing.
    const keys: number[] = [];
    let highest = 0;
    let looking = false;
    let peak = -Infinity;
    let peakIndex = -1;
    for (let i = 1; i <= maxLag; i++) {
      if (nsdf[i - 1] <= 0 && nsdf[i] > 0) {
        looking = true;
        peak = nsdf[i];
        peakIndex = i;
      } else if (nsdf[i - 1] > 0 && nsdf[i] <= 0) {
        if (looking && peakIndex >= minLag) {
          keys.push(peakIndex);
          highest = Math.max(highest, peak);
        }
        looking = false;
      } else if (looking && nsdf[i] > peak) {
        peak = nsdf[i];
        peakIndex = i;
      }
    }
    if (looking && peakIndex >= minLag && peakIndex < maxLag) {
      keys.push(peakIndex);
      highest = Math.max(highest, peak);
    }
    if (keys.length === 0) return { hz: null, clarity: 0 };

    // The first key maximum close to the highest one is the fundamental period.
    const index = keys.find((i) => nsdf[i] >= k * highest)!;
    const y0 = nsdf[index - 1];
    const y1 = nsdf[index];
    const y2 = nsdf[index + 1];
    const curvature = y0 - 2 * y1 + y2;
    const shift = curvature === 0 ? 0 : (0.5 * (y0 - y2)) / curvature;
    const clarity = Math.min(1, Math.max(0, y1 - 0.25 * (y0 - y2) * shift));
    return { hz: sampleRate / (index + shift), clarity };
  };
}
```

```ts
import { hzToMidi, midiToHz } from "../dsp/music";
import { median } from "../dsp/stats";

/** One pitch estimate. `t` is seconds on the audio clock at the window center. */
export type PitchFrame = { t: number; hz: number | null; clarity: number; rms: number };

/**
 * Median-of-N smoothing with an octave guard. A jump of 1100-1300 cents that
 * lasts less than `octaveHoldS` is treated as a detector error and replaced by
 * the previous pitch; one that lasts longer is accepted as real.
 */
export class LiveSmoother {
  private recent: number[] = [];
  private lastVoicedT = -Infinity;
  private jumpStartT: number | null = null;
  private readonly medianSize: number;
  private readonly octaveHoldS: number;
  private readonly resetGapS: number;

  constructor(medianSize = 5, octaveHoldS = 0.06, resetGapS = 0.15) {
    this.medianSize = medianSize;
    this.octaveHoldS = octaveHoldS;
    this.resetGapS = resetGapS;
  }

  reset(): void {
    this.recent = [];
    this.jumpStartT = null;
  }

  push(frame: PitchFrame): PitchFrame {
    if (frame.hz === null) return frame;
    if (frame.t - this.lastVoicedT > this.resetGapS) this.reset();
    this.lastVoicedT = frame.t;

    const midi = hzToMidi(frame.hz);
    if (this.recent.length > 0) {
      const reference = median(this.recent);
      const jumpCents = Math.abs(midi - reference) * 100;
      if (jumpCents >= 1100 && jumpCents <= 1300) {
        if (this.jumpStartT === null) this.jumpStartT = frame.t;
        if (frame.t - this.jumpStartT < this.octaveHoldS) return { ...frame, hz: midiToHz(reference) };
        this.recent = [];
      }
    }
    this.jumpStartT = null;

    this.recent.push(midi);
    if (this.recent.length > this.medianSize) this.recent.shift();
    return { ...frame, hz: midiToHz(median(this.recent)) };
  }
}
```

```ts
/**
 * Collects audio blocks of any length into fixed-size chunks. Each chunk is a
 * new buffer, so the receiver may transfer it to another thread.
 */
export class Chunker {
  private buffer: Float32Array<ArrayBuffer>;
  private fill = 0;
  private frame0 = 0;
  private readonly size: number;
  private readonly emit: (chunk: Float32Array<ArrayBuffer>, frame0: number) => void;

  constructor(size: number, emit: (chunk: Float32Array<ArrayBuffer>, frame0: number) => void) {
    this.size = size;
    this.emit = emit;
    this.buffer = new Float32Array(size);
  }

  /** `blockFrame` is the audio-clock frame number of the block's first sample. */
  push(block: Float32Array, blockFrame: number): void {
    let offset = 0;
    while (offset < block.length) {
      if (this.fill === 0) this.frame0 = blockFrame + offset;
      const n = Math.min(this.size - this.fill, block.length - offset);
      this.buffer.set(block.subarray(offset, offset + n), this.fill);
      this.fill += n;
      offset += n;
      if (this.fill === this.size) {
        const full = this.buffer;
        this.buffer = new Float32Array(this.size);
        this.fill = 0;
        this.emit(full, this.frame0);
      }
    }
  }
}
```

```ts
import { createBandMpm, type Band, type Estimate } from "./bandMpm";
import { LiveSmoother, type PitchFrame } from "./smoother";

export type AnalyzerConfig = {
  sampleRate: number;
  windowSize: number;
  band: Band;
  clarityMin: number;
  rmsMin: number;
};

/** Keeps the most recent window of audio and produces one pitch frame per chunk. */
export class LiveAnalyzer {
  private readonly config: AnalyzerConfig;
  private readonly window: Float32Array;
  private readonly detect: (input: Float32Array) => Estimate;
  private readonly smoother = new LiveSmoother();
  private filled = 0;
  private rmsMin: number;

  constructor(config: AnalyzerConfig) {
    this.config = config;
    this.window = new Float32Array(config.windowSize);
    this.detect = createBandMpm(config.windowSize, config.sampleRate, config.band);
    this.rmsMin = config.rmsMin;
  }

  setRmsMin(value: number): void {
    this.rmsMin = value;
  }

  /** `frame0` is the audio-clock frame number of the chunk's first sample. */
  push(samples: Float32Array, frame0: number): PitchFrame | null {
    const size = this.config.windowSize;
    const n = samples.length;
    if (n >= size) {
      this.window.set(samples.subarray(n - size));
    } else {
      this.window.copyWithin(0, n);
      this.window.set(samples, size - n);
    }
    this.filled = Math.min(size, this.filled + n);
    if (this.filled < size) return null;

    let sum = 0;
    for (let i = 0; i < n; i++) sum += samples[i] * samples[i];
    const rms = Math.sqrt(sum / n);

    const estimate = this.detect(this.window);
    const voiced = estimate.hz !== null && estimate.clarity >= this.config.clarityMin && rms >= this.rmsMin;
    const t = (frame0 + n - size / 2) / this.config.sampleRate;
    return this.smoother.push({ t, hz: voiced ? estimate.hz : null, clarity: estimate.clarity, rms });
  }
}
```

```ts
  const entry = devices.find((d) => d.kind === "audiooutput" && d.deviceId === "default");
  return entry ? entry.label.replace(/^Default\s*-\s*/i, "") : "";
}

export type OutputKind = "headphones" | "speakers" | "unknown";

export function classifyOutput(label: string): OutputKind {
  if (/AirPods|Beats|Headphones|Buds|Bose|Sony/i.test(label)) return "headphones";
  if (/Speakers/i.test(label)) return "speakers";
  return "unknown";
}

export const routeKey = (outputLabel: string, inputLabel: string): string => `${outputLabel} | ${inputLabel}`;
```

```ts
/** Encodes mono samples in [-1, 1] as a 16-bit PCM WAV file. */
export function encodeWav(samples: Float32Array, sampleRate: number): ArrayBuffer {
  const dataBytes = samples.length * 2;
  const buffer = new ArrayBuffer(44 + dataBytes);
  const view = new DataView(buffer);
  const text = (offset: number, value: string) => {
    for (let i = 0; i < value.length; i++) view.setUint8(offset + i, value.charCodeAt(i));
  };
  text(0, "RIFF");
  view.setUint32(4, 36 + dataBytes, true);
  text(8, "WAVE");
  text(12, "fmt ");
  view.setUint32(16, 16, true);
  view.setUint16(20, 1, true);
  view.setUint16(22, 1, true);
  view.setUint32(24, sampleRate, true);
  view.setUint32(28, sampleRate * 2, true);
  view.setUint16(32, 2, true);
  view.setUint16(34, 16, true);
  text(36, "data");
  view.setUint32(40, dataBytes, true);
  for (let i = 0; i < samples.length; i++) {
    const clipped = Math.max(-1, Math.min(1, samples[i]));
    view.setInt16(44 + i * 2, Math.round(clipped * 32767), true);
  }
  return buffer;
}
```

```ts
import type { AnalyzerConfig } from "../pitch/liveAnalyzer";
import type { LiveWorkerMessage } from "../pitch/live.worker";
import type { PitchFrame } from "../pitch/smoother";
import captureUrl from "./capture.worklet.ts?worker&url";
import {
  BUILT_IN_MIC,
  classifyOutput,
  defaultOutputLabel,
  micConstraints,
  pickMic,
  processingWarnings,
  type OutputKind,
} from "./devices";

export type EngineInfo = {
  sampleRate: number;
  baseLatencyMs: number;
  outputLatencyMs: number;
  micLabel: string;
  micIsBuiltIn: boolean;
  outputLabel: string;
  outputKind: OutputKind;
  applied: MediaTrackSettings;
  warnings: string[];
};

/** `startFrame` is the audio-clock frame number of `pcm[0]`. */
export type Capture = { pcm: Float32Array<ArrayBuffer>; sampleRate: number; startFrame: number };

type Chunk = { samples: Float32Array<ArrayBuffer>; frame0: number };

/** One audio context, one pinned microphone, one stream of pitch frames. */
export class AudioEngine {
  private context: AudioContext | null = null;
  private worker: Worker | null = null;
  private track: MediaStreamTrack | null = null;
  private current: EngineInfo | null = null;
  private capture: { chunks: Float32Array[]; startFrame: number } | null = null;
  private debounce: ReturnType<typeof setTimeout> | null = null;
  private readonly frameListeners = new Set<(frame: PitchFrame) => void>();
  private readonly deviceListeners = new Set<(info: EngineInfo) => void>();
  private readonly micPattern: RegExp;

  constructor(options: { micPattern?: RegExp } = {}) {
    this.micPattern = options.micPattern ?? BUILT_IN_MIC;
  }

  get ctx(): AudioContext {
    if (!this.context) throw new Error("The audio engine has not been started.");
    return this.context;
  }

  get info(): EngineInfo {
    if (!this.current) throw new Error("The audio engine has not been started.");
    return this.current;
  }

  /** Must be called from a click. Call it before any audio plays. */
  async start(): Promise<EngineInfo> {
    // A throwaway request to obtain permission. macOS may route it to the
    // AirPods microphone, so it is stopped at once and never used.
    const probe = await navigator.mediaDevices.getUserMedia({ audio: true });
    probe.getTracks().forEach((track) => track.stop());

    const devices = await navigator.mediaDevices.enumerateDevices();
    const mic = pickMic(devices, this.micPattern);
    if (!mic) {
      const seen = devices.filter((d) => d.kind === "audioinput").map((d) => d.label);
      throw new Error(`Built-in microphone not found. Inputs seen: ${seen.join(", ") || "none"}.`);
    }
    const stream = await navigator.mediaDevices.getUserMedia(micConstraints(mic.deviceId));
    this.track = stream.getAudioTracks()[0];

    const ctx = new AudioContext({ latencyHint: "interactive" });
    this.context = ctx;
    await ctx.audioWorklet.addModule(captureUrl);
    const node = new AudioWorkletNode(ctx, "capture", { numberOfInputs: 1, numberOfOutputs: 1 });
    // Routed through a silent gain so the browser keeps processing the node.
    const silent = ctx.createGain();
    silent.gain.value = 0;
    ctx.createMediaStreamSource(stream).connect(node).connect(silent).connect(ctx.destination);

    const worker = new Worker(new URL("../pitch/live.worker.ts", import.meta.url), { type: "module" });
    this.worker = worker;
    const config: AnalyzerConfig = {
      sampleRate: ctx.sampleRate,
      windowSize: 2048,
      band: { minHz: 55, maxHz: 700 },
      clarityMin: 0.5,
      rmsMin: 0,
    };
    this.send({ type: "config", config });
    worker.onmessage = (event: MessageEvent<PitchFrame>) => {
      for (const listener of this.frameListeners) listener(event.data);
    };
    node.port.onmessage = (event: MessageEvent<Chunk>) => {
      const { samples, frame0 } = event.data;
      if (this.capture) {
        if (this.capture.chunks.length === 0) this.capture.startFrame = frame0;
        this.capture.chunks.push(samples.slice());
      }
      this.send({ type: "chunk", samples, frame0 }, [samples.buffer]);
    };

    navigator.mediaDevices.addEventListener("devicechange", this.handleDeviceChange);
    await ctx.resume();
    this.current = await this.readInfo();
    return this.current;
  }

  onFrame(listener: (frame: PitchFrame) => void): () => void {
    this.frameListeners.add(listener);
    return () => {
      this.frameListeners.delete(listener);
    };
  }

  onDeviceChange(listener: (info: EngineInfo) => void): () => void {
    this.deviceListeners.add(listener);
    return () => {
      this.deviceListeners.delete(listener);
    };
  }

  /** Frames quieter than `rmsMin` are reported as unvoiced. */
  setRmsGate(rmsMin: number): void {
    this.send({ type: "gate", rmsMin });
  }

  /** Starts keeping microphone audio. Call `end()` to get it back. */
  beginCapture(): { end: () => Capture } {
    const capture = { chunks: [] as Float32Array[], startFrame: 0 };
    this.capture = capture;
    return {
      end: () => {
        if (this.capture === capture) this.capture = null;
        const total = capture.chunks.reduce((sum, chunk) => sum + chunk.length, 0);
        const pcm = new Float32Array(total);
        let offset = 0;
        for (const chunk of capture.chunks) {
          pcm.set(chunk, offset);
          offset += chunk.length;
        }
        return { pcm, sampleRate: this.ctx.sampleRate, startFrame: capture.startFrame };
      },
    };
  }

  private send(message: LiveWorkerMessage, transfer: Transferable[] = []): void {
    this.worker?.postMessage(message, transfer);
  }

  // Chrome fires several events for one physical change, so wait for them to settle.
  private handleDeviceChange = (): void => {
    if (this.debounce) clearTimeout(this.debounce);
    this.debounce = setTimeout(async () => {
      this.current = await this.readInfo();
      for (const listener of this.deviceListeners) listener(this.current);
    }, 500);
  };

  private async readInfo(): Promise<EngineInfo> {
    const ctx = this.ctx;
    const track = this.track!;
    const outputLabel = defaultOutputLabel(await navigator.mediaDevices.enumerateDevices());
    const applied = track.getSettings();
    const micIsBuiltIn = track.readyState === "live" && this.micPattern.test(track.label);
    const warnings = processingWarnings(applied);
    if (!micIsBuiltIn) warnings.push("The live microphone is not the built-in one. Scoring must be blocked.");
    return {
      sampleRate: ctx.sampleRate,
      baseLatencyMs: ctx.baseLatency * 1000,
      outputLatencyMs: ctx.outputLatency * 1000,
      micLabel: track.label,
      micIsBuiltIn,
      outputLabel,
      outputKind: classifyOutput(outputLabel),
      applied,
      warnings,
    };
  }
}
```

```tsx
import { useEffect, useRef } from "react";
import type { AudioEngine } from "../audio/engine";
import { hzToMidi, midiToName } from "../dsp/music";
import type { PitchFrame } from "../pitch/smoother";

const SECONDS = 6;
const LOW_MIDI = 33; // A1
const HIGH_MIDI = 69; // A4

/** A scrolling pitch line. Drawn from a plain array on each animation frame; nothing goes through React state. */
export function PitchCanvas({ engine }: { engine: AudioEngine }) {
  const ref = useRef<HTMLCanvasElement>(null);

  useEffect(() => {
    const canvas = ref.current!;
    const g = canvas.getContext("2d")!;
    const frames: PitchFrame[] = [];
    const unsubscribe = engine.onFrame((frame) => {
      frames.push(frame);
      while (frame.t - frames[0].t > SECONDS) frames.shift();
    });

    let animation = 0;
    const draw = () => {
      const { width, height } = canvas;
      const y = (midi: number) => height - ((midi - LOW_MIDI) / (HIGH_MIDI - LOW_MIDI)) * height;
      g.fillStyle = "#0b1020";
      g.fillRect(0, 0, width, height);
      g.font = "11px system-ui";
      for (let midi = LOW_MIDI; midi <= HIGH_MIDI; midi++) {
        const isC = midi % 12 === 0;
        g.strokeStyle = isC ? "#3b4a6b" : "#1c2540";
        g.beginPath();
        g.moveTo(0, y(midi));
        g.lineTo(width, y(midi));
        g.stroke();
        if (isC) {
          g.fillStyle = "#8fa3c8";
          g.fillText(midiToName(midi), 4, y(midi) - 3);
        }
      }
      const now = frames.length > 0 ? frames[frames.length - 1].t : 0;
      g.fillStyle = "#7dd3fc";
      for (const frame of frames) {
        if (frame.hz === null) continue;
        const x = width - ((now - frame.t) / SECONDS) * width;
        g.fillRect(x - 1, y(hzToMidi(frame.hz)) - 1, 3, 3);
      }
      animation = requestAnimationFrame(draw);
    };
    animation = requestAnimationFrame(draw);

    return () => {
      unsubscribe();
      cancelAnimationFrame(animation);
    };
  }, [engine]);

  return <canvas ref={ref} width={900} height={360} className="w-full rounded border border-slate-700" />;
}
```

```ts
/** A short rising sweep with a smooth start and end. Its correlation peak is one sample wide. */
export function makeChirp(sampleRate: number, ms = 30, fromHz = 1500, toHz = 6000): Float32Array<ArrayBuffer> {
  const n = Math.round((sampleRate * ms) / 1000);
  const out = new Float32Array(n);
  const duration = n / sampleRate;
  for (let i = 0; i < n; i++) {
    const t = i / sampleRate;
    const phase = 2 * Math.PI * (fromHz * t + ((toHz - fromHz) * t * t) / (2 * duration));
    const window = 0.5 * (1 - Math.cos((2 * Math.PI * i) / (n - 1)));
    out[i] = Math.sin(phase) * window;
  }
  return out;
}

/**
 * Finds where `reference` best matches inside `captured`, trying start
 * positions `from` to `to` inclusive. `to` must be at most
 * `captured.length - reference.length`.
 */
export function findDelay(
  captured: Float32Array,
  reference: Float32Array,
  from: number,
  to: number,
): { index: number; score: number } {
  let referenceEnergy = 0;
  for (let j = 0; j < reference.length; j++) referenceEnergy += reference[j] * reference[j];
  let best = { index: from, score: -Infinity };
  for (let start = from; start <= to; start++) {
    let dot = 0;
    let energy = 0;
    for (let j = 0; j < reference.length; j++) {
      const sample = captured[start + j];
      dot += sample * reference[j];
      energy += sample * sample;
    }
    const score = dot / Math.sqrt(energy * referenceEnergy + 1e-12);
    if (score > best.score) best = { index: start, score };
  }
  return best;
}
```

```ts
import { median } from "../dsp/stats";
import { findDelay, makeChirp } from "./chirp";
import type { AudioEngine } from "./engine";

export type ChirpResult = { delayMs: number; score: number };

export type CalibrationResult = {
  roundTripMs: number | null;
  spreadMs: number | null;
  accepted: boolean;
  chirps: ChirpResult[];
};

/** A chirp counts as heard at this correlation or better. */
export const MIN_SCORE = 0.3;
export const MAX_SPREAD_MS = 5;
const MAX_DELAY_S = 0.6;

/** Chirp start times in seconds: irregular, and further apart than the longest delay searched. */
export const CHIRP_OFFSETS_S = [0, 0.71, 1.53, 2.27, 3.09, 3.83, 4.71, 5.47];

/**
 * The round trip is the median delay of the chirps that were heard. The spread
 * is the range of those delays after dropping the lowest and the highest.
 */
export function summarize(chirps: ChirpResult[]): CalibrationResult {
  const delays = chirps
    .filter((chirp) => chirp.score >= MIN_SCORE)
    .map((chirp) => chirp.delayMs)
    .sort((a, b) => a - b);
  if (delays.length < 6) return { roundTripMs: null, spreadMs: null, accepted: false, chirps };
  const core = delays.slice(1, -1);
  const spreadMs = core[core.length - 1] - core[0];
  return { roundTripMs: median(delays), spreadMs, accepted: spreadMs < MAX_SPREAD_MS, chirps };
}

/**
 * Plays chirps and times their arrival at the microphone. The result is the
 * output delay plus the input delay: the amount to subtract from capture times
 * when comparing singing with playback.
 */
export async function runCalibration(engine: AudioEngine, volume = 0.5): Promise<CalibrationResult> {
  const ctx = engine.ctx;
  const sampleRate = ctx.sampleRate;
  const chirp = makeChirp(sampleRate);
  const buffer = ctx.createBuffer(1, chirp.length, sampleRate);
  buffer.copyToChannel(chirp, 0);
  const gain = ctx.createGain();
  gain.gain.value = volume;
  gain.connect(ctx.destination);

  const capture = engine.beginCapture();
  const firstChirp = ctx.currentTime + 0.3;
  const times = CHIRP_OFFSETS_S.map((offset) => firstChirp + offset);
  for (const time of times) {
    const source = ctx.createBufferSource();
    source.buffer = buffer;
    source.connect(gain);
    source.start(time);
  }
  const lastChirp = times[times.length - 1];
  const waitMs = (lastChirp - ctx.currentTime + MAX_DELAY_S + 0.3) * 1000;
  await new Promise((resolve) => setTimeout(resolve, waitMs));
  const { pcm, startFrame } = capture.end();
  gain.disconnect();

  const maxDelay = Math.round(MAX_DELAY_S * sampleRate);
  const chirps = times.map((time) => {
    const expected = Math.round(time * sampleRate) - startFrame;
    const from = Math.max(0, expected);
    const to = Math.min(pcm.length - chirp.length, expected + maxDelay);
    const { index, score } = findDelay(pcm, chirp, from, to);
    return { delayMs: ((index - expected) / sampleRate) * 1000, score };
  });
  return summarize(chirps);
}
```

```ts
export function loadJson<T>(key: string, fallback: T): T {
  try {
    const raw = localStorage.getItem(key);
    return raw === null ? fallback : (JSON.parse(raw) as T);
  } catch {
    return fallback;
  }
}

export function saveJson(key: string, value: unknown): void {
  localStorage.setItem(key, JSON.stringify(value));
}

/** Saves `data` to the Downloads folder under `filename`. */
export function download(filename: string, data: BlobPart, type: string): void {
  const url = URL.createObjectURL(new Blob([data], { type }));
  const link = document.createElement("a");
  link.href = url;
  link.download = filename;

  URL.revokeObjectURL(url);
```

```ts
import { centsBetween } from "../dsp/music";
import { median, percentile } from "../dsp/stats";
import { createBandMpm, type Band } from "../pitch/bandMpm";

export type DetectorStats = {
  windowSize: number;
  frames: number;
  voicedPct: number;
  medianHz: number | null;
  octaveErrorPct: number;
  spreadCents: number | null;
};

/** Runs the detector over a clip of one held note and reports how steadily it tracked. */
export function analyzeSustained(
  pcm: Float32Array,
  sampleRate: number,
  windowSize: number,
  band: Band,
  hop = 512,
): DetectorStats {
  const detect = createBandMpm(windowSize, sampleRate, band);
  const voiced: number[] = [];
  let frames = 0;
  for (let start = 0; start + windowSize <= pcm.length; start += hop) {
    frames++;
    const estimate = detect(pcm.subarray(start, start + windowSize));
    if (estimate.hz !== null && estimate.clarity >= 0.5) voiced.push(estimate.hz);
  }
  if (voiced.length === 0) {
    return { windowSize, frames, voicedPct: 0, medianHz: null, octaveErrorPct: 0, spreadCents: null };
  }
  const medianHz = median(voiced);
  const cents = voiced.map((hz) => centsBetween(hz, medianHz));
  const octaveErrors = cents.filter((c) => Math.abs(c) >= 1100 && Math.abs(c) <= 1300).length;
  const nearMedian = cents.filter((c) => Math.abs(c) < 600);
  return {
    windowSize,
    frames,
    voicedPct: (100 * voiced.length) / frames,
    medianHz,
    octaveErrorPct: (100 * octaveErrors) / voiced.length,
    spreadCents: percentile(nearMedian, 0.9) - percentile(nearMedian, 0.1),
  };
}

/** Power at one frequency, using a Hann window. */
function powerAt(samples: Float32Array, sampleRate: number, hz: number): number {
  const coefficient = 2 * Math.cos((2 * Math.PI * hz) / sampleRate);
  const n = samples.length;
  let s1 = 0;
  let s2 = 0;
  for (let i = 0; i < n; i++) {
    const window = 0.5 * (1 - Math.cos((2 * Math.PI * i) / (n - 1)));
    const s0 = samples[i] * window + coefficient * s1 - s2;
    s2 = s1;
    s1 = s0;
  }
  return s1 * s1 + s2 * s2 - coefficient * s1 * s2;
}

function loudestSegment(pcm: Float32Array, size: number): Float32Array {
  let bestStart = 0;
  let bestEnergy = -1;
  for (let start = 0; start + size <= pcm.length; start += size / 4) {
    let energy = 0;
    for (let i = start; i < start + size; i++) energy += pcm[i] * pcm[i];
    if (energy > bestEnergy) {
      bestEnergy = energy;
      bestStart = start;
    }
  }
  return pcm.subarray(bestStart, bestStart + size);
}

/**
 * For each of the first `harmonics` harmonics of `f0`: its level in dB above
 * the level halfway to the neighboring harmonics. Shows whether the microphone
 * picks up the low part of a voice.
 */
export function harmonicSnrDb(pcm: Float32Array, sampleRate: number, f0: number, harmonics = 5, size = 8192): number[] {
  if (pcm.length < size) return [];
  const segment = loudestSegment(pcm, size);
  const result: number[] = [];
  for (let k = 1; k <= harmonics; k++) {
    const signal = powerAt(segment, sampleRate, k * f0);
    const below = powerAt(segment, sampleRate, (k - 0.5) * f0);
    const above = powerAt(segment, sampleRate, (k + 0.5) * f0);
    result.push(10 * Math.log10(signal / Math.max((below + above) / 2, 1e-20)));
  }
  return result;
}
```

```python
# /// script
# requires-python = ">=3.10"
# dependencies = ["swift-f0[audio]", "numpy"]
# ///
"""Print SwiftF0 statistics for held-note clips saved from the audio lab.

Usage: uv run tools/f0_compare.py clip1.wav [clip2.wav ...]
"""
import sys

import numpy as np
from swift_f0 import SwiftF0


def summarize(detector: SwiftF0, path: str) -> str:
    result = detector.detect_file(path, fmin=55, fmax=700)
    voiced = result.confidence >= 0.5
    frames = len(result.pitch_hz)
    if not voiced.any():
        return f"{path}: {frames} frames, none voiced"
    hz = result.pitch_hz[voiced]
    median_hz = float(np.median(hz))
    cents = 1200 * np.log2(hz / median_hz)
    octave = (np.abs(cents) >= 1100) & (np.abs(cents) <= 1300)
    near = cents[np.abs(cents) < 600]
    spread = float(np.percentile(near, 90) - np.percentile(near, 10))
    return (
        f"{path}: {frames} frames, voiced {100 * voiced.mean():.1f}%, "
        f"median {median_hz:.2f} Hz, octave errors {100 * octave.mean():.2f}% of voiced, "
        f"spread {spread:.1f} cents"
    )


def main() -> None:
    if len(sys.argv) < 2:
        sys.exit(__doc__)
    detector = SwiftF0()
    for path in sys.argv[1:]:
        print(summarize(detector, path))


if __name__ == "__main__":
    main()
```

```ts
import { median } from "../dsp/stats";

/** The loudness gate: 10 dB above the room's median level. */
export function noiseGate(rmsValues: number[]): number {
  return rmsValues.length === 0 ? 0 : median(rmsValues) * 10 ** (10 / 20);
}

/** The share of frames in which a pitch was detected, 0 to 100. */
export function voicedPct(frames: { hz: number | null }[]): number {
  if (frames.length === 0) return 0;
  return (100 * frames.filter((frame) => frame.hz !== null).length) / frames.length;
}
```

```tsx
export function LeakagePanel({ engine }: { engine: AudioEngine }) {
  const [buffer, setBuffer] = useState<AudioBuffer | null>(null);
  const [volume, setVolume] = useState(0.5);
  const [gate, setGate] = useState<number | null>(null);
  const [leak, setLeak] = useState<number | null>(null);
  const [busy, setBusy] = useState(false);

  async function measureRoom() {
    setBusy(true);
    engine.setRmsGate(0);
    const levels: number[] = [];
    const unsubscribe = engine.onFrame((frame) => levels.push(frame.rms));
    await wait(3000);
    unsubscribe();
    const value = noiseGate(levels);
    engine.setRmsGate(value);
    setGate(value);
    setBusy(false);
  }

  async function load(file: File) {
    setBuffer(await engine.ctx.decodeAudioData(await file.arrayBuffer()));
  }

  async function play(measure: boolean) {
    if (!buffer) return;

    const gain = engine.ctx.createGain();
    gain.gain.value = volume;
    source.connect(gain).connect(engine.ctx.destination);
    const frames: PitchFrame[] = [];
    const unsubscribe = measure ? engine.onFrame((frame) => frames.push(frame)) : () => {};
    // Start partway in, past any quiet introduction.
    source.start(0, Math.min(30, buffer.duration / 2), SECONDS);
    await wait(SECONDS * 1000 + 300);
    unsubscribe();
    gain.disconnect();
    if (measure) setLeak(voicedPct(frames));
    setBusy(false);
```
